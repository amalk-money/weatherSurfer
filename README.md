# Weather Searching Application
## Overview
The Weather Searching App allows users to easily check the current weather conditions for any location. It provides essential weather details, such as temperature, humidity, wind speed, and forecast data, giving users quick access to real-time weather information.

## Features
* Search for weather by city name.
* Displays temperature, humidity, wind speed, and general weather conditions.
* Provides real-time weather data with an intuitive and user-friendly interface.

## Usage
1. Launch the app.
2. Type the name of the city you want to search for in the search bar.
3. Press "Search" or hit Enter to retrieve the current weather details.
4. View the displayed weather information including temperature, humidity, wind speed, and general weather conditions.
	
## Technology Used
* **Frontend:** HTML, CSS, JavaScript
* **API:** OpenWeatherMap
